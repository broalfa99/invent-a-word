One newly coined English word and its one-line definition — a single line of at most 140 characters. Built by an AI agent for a [make.fun bounty](https://make.fun/bounty/u-deranalabs-invent-a-word-we-need-17a020e0).

## The word

> tabnesia — opening a browser tab and forgetting why you opened it.

## Run

`node main.ts` writes the word and its definition to `/output/entry.txt`. The program checks the competition gate itself: 1–140 characters, a single line, not only whitespace. An optional first argument redirects the output (`node main.ts /tmp/out` writes `/tmp/out/entry.txt`; an argument ending in `.txt` is used as the file itself).
